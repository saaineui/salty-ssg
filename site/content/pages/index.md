## Why use Salty SSG

Not every static site needs React and Webpack processes designed for enterprise apps.

Content can be maintained in a code editor and tracked in git instead of maintaining a CMS database and admin interface.

Salty SSG is a return to a quiet, minimalist web of yore but with modern tooling and standards: Python, Markdown, YAML.

## You are in control, not your bloat

Do these headaches sound familiar?
- Hydration errors leading to failing tests.
- Urgent security bugs from a dependency that you didn't even know you had.
- SEO metadata locked in a CMS database that you only run locally.

It's your website, and you should be the one driving upkeep: only work on your site when you have changes to make.
